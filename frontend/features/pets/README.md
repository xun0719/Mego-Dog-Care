# 毛孩資料模組

- `petFormContent.ts`：毛孩表單欄位定義。
- `memorialContent.ts`：回憶模式的日期檢查、紀念期間與陪伴時間文字、照顧中／回憶中毛孩分組；設定前與二次確認共用保留／停止事項。
- `screens/PetMemorialScreen.tsx`：移到回憶（離開日期、紀念文字、二次確認）與還原；入口在編輯毛孩資料最下方。
- `components/MemorialPetCard.tsx`：設定前使用精簡橫向毛孩卡；設定後使用置中紀念卡，呈現頭像、姓名、日期、陪伴期間及完整留言。
- `memorialStyles.ts`：回憶畫面樣式，與操作邏輯分開維護；使用既有暖灰色與彈性卡片高度。
- 回憶頁使用與日常相同的 `ScreenPageHeader` 和安全區域；首頁與設定兩個 Stack 均關閉此頁的原生標題，避免從首頁進入時出現兩層頁首。照顧中顯示「移到回憶」，回憶中及未選擇毛孩時顯示「回憶」，均可返回。編輯毛孩資料的未選擇狀態也保留頁首，不顯示空白頁。
- `components/PetAvatarPicker.tsx`：相簿／相機照片操作與展示。
- `components/PetIdentityCarousel.tsx`：共用毛孩身分卡，提供選取、滑動切換與編輯入口；設定與首頁毛孩選擇器共用。
- `components/PetFormTextField.tsx`：文字與日期欄位外觀。
- `../../screens/PetFormScreen.tsx`：欄位狀態、驗證、送出 callback 與性別／品種類型選擇。
- 毛孩資料表單的儲存與取消按鈕間隔使用共用 `FORM_FIELD_GAP`（16），不再讓兩個描邊／底色框貼在一起。
- 性別與品種類型使用共用表單版 `SelectionChip`，維持原有等寬欄位，並提供單選群組名稱及選取狀態；不改既有欄位值或驗證。

圖片權限、`PetData` 結構與建立／更新流程未更動。

`PetFormTextField` 接受 `error` 與 `onLayout`，錯誤顯示在欄位下方（`components/FieldError.tsx`）。姓名、品種、性別、出生日期與到家日期分別標示，原本四個必填欄位合併成一則提示、使用者要自行找出是哪一個的問題已修正；送出時捲到第一個出錯的欄位並震動一次。移到回憶的日期檢查同樣改為欄位錯誤，不使用對話框。

## 回憶頁流程

- 設定前分為「這次設定的毛孩」「設定後會有哪些變化」「留下紀念」。說明以「會保留／會停止」分組，不把停止事項畫成綠色完成勾勾。
- 離開日期預設空白，必須主動選擇；只可選今天或以前，且不可早於生日與到家日。未選擇或日期不符時在欄位下顯示錯誤，不會送出或顯示確認視窗。
- 「想對牠說的話（選填）」沿用日常頁的 `SupplementalNotesField` 獨立編輯視窗，保留 300 字限制；打開柔和進場，取消不改留言，關閉立即隱藏並收起鍵盤。
- 確認移到回憶前保留系統二次確認；成功後沿用返回上一頁的流程。雲端資料及照片保留，停止未完成提醒與本機通知、關閉身分 QR 公開頁的規則不變。
- 再次開啟回憶頁顯示紀念卡，下方提供「查看照護紀錄／查看照護相簿」。跳轉前會選取目前紀念頁的毛孩，再前往紀錄分頁的對應頁面，避免讀到另一隻毛孩。
- 「從回憶還原」收在最下方的「誤設處理」，保留二次確認；已停止的提醒不自動恢復。
- `__tests__/petMemorialScreen.test.tsx` 驗證空白必填日期、台灣日期邊界、獨立留言編輯、確認／取消、失敗保留輸入、紀念卡、跨分頁回顧、還原與無毛孩狀態。`features/settings/__tests__/settingsNavigation.test.ts` 另檢查首頁及設定兩個入口的系統頁首設定。
